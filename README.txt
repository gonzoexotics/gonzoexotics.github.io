ZDROWIE / CHOROBY / PROBLEMY / PROFILAKTYKA

Dla Morelia viridis, Corallus caninus i Python bivittatus dodano m.in.:
- serpentowirusy / nidowirusy,
- choroby dróg oddechowych,
- stomatitis / mouth rot,
- BIBD / reptarenawirusy,
- Ophionyssus natricis (roztocze),
- problemy skórne / dermatitis / tzw. scale rot,
- oparzenia,
- dysecdysis i retained eyecaps,
- prolaps kloaki/jelita/narządów rozrodczych,
- pasożyty wewnętrzne i płucne,
- Cryptosporidium serpentis,
- dystocję i problemy rozrodcze,
- objawy alarmowe,
- badania diagnostyczne,
- zasady leczenia i pierwszej reakcji,
- pełną bioasekurację kolekcji,
- kwarantannę i screening.

Bezpieczeństwo:
- nie podano losowych dawek leków,
- antybiotyki/przeciwpasożytnicze i zabiegi są przypisane do diagnostyki weterynaryjnej,
- wyraźnie zaznaczono choroby bez skutecznego leczenia przyczynowego (BIBD, C. serpentis; serpentowirus — brak swoistego leku),
- prolaps i dystocja oznaczone jako stany pilne.
