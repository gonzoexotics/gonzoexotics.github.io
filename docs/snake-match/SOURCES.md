# Źródła danych dla Gonzo Snake Match

Każdy profil w `assets/js/snake-data.js` zawiera własne źródła i datę weryfikacji.

Źródła wspólne:
- The Reptile Database — kontrola nazewnictwa naukowego: https://reptile-database.reptarium.cz/
- RDOŚ — regulacje dotyczące gatunków CITES: https://www.gov.pl/web/rdos-poznan/regulacje-dotyczace-gatunkow-cites

Źródła praktyki hodowlanej:
- ReptiFiles — Corn Snake Care Guide
- ReptiFiles — Ball Python Care Guide
- ReptiFiles — Boa Care Guide
- ReptiFiles — Kingsnake Care Sheet
- ReptiFiles — Green Tree Python Care Sheet
- ReptiFiles — Northern Emerald Tree Boa Care Sheet
- ReptiFiles — Burmese Python Care Sheet
- ReptiFiles — Snake Care Sheets

Materiały ReptiFiles są użyte jako specjalistyczny, konserwatywny punkt wyjścia do parametrów utrzymania. Nie zastępują aktualnych opracowań pierwotnych ani weryfikacji potrzeb konkretnego zwierzęcia.
