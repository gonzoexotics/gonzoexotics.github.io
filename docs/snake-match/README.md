# Gonzo Snake Match — utrzymanie i rozszerzanie

Strony: /jaki-waz-dla-ciebie/ i /porownaj-weze/.

Jedna baza danych: assets/js/snake-data.js. Każdy nowy gatunek musi mieć pełne dane, blokady bezpieczeństwa i źródła z datą kontroli. Brak pewności oznacza needsReview: true — profil nie może trafić do wyniku.

Quiz ma 15 pytań. Wynik zawsze pokazuje TOP 3 jako trzy możliwe kierunki, nie jeden „idealny” gatunek. Blokady mają pierwszeństwo nad punktacją: zwłaszcza zbyt mała przestrzeń, za małe doświadczenie w gatunkach zaawansowanych, brak akceptacji dużej karmówki, brak planu dorosłego terrarium i zbyt mało czasu na wymagający mikroklimat.

## Zdjęcia

Prywatne zdjęcia Gonzo Exotics pozostają przy Morelia viridis, Corallus caninus i Python bivittatus. Dla pozostałych gatunków wykorzystano zdjęcia zewnętrzne z podpisem i linkiem do źródła widocznym w wyniku. Przed zastąpieniem ich zdjęciem własnym wpisz ścieżkę w mapie externalVisuals i zmień podpis na „Zdjęcie: Gonzo Exotics”. Nigdy nie używaj zdjęcia innego gatunku.
