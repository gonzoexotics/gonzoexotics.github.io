# Privacy checklist

- [ ] Uzupełnij administratora danych i kanał kontaktowy.
- [ ] Sporządź rzeczywistą mapę danych: e-mail, zamówienia, płatności, wysyłka, reklamacje.
- [ ] Ustal podstawy prawne, odbiorców danych i okresy retencji dla faktycznych procesów.
- [ ] Zawieraj umowy powierzenia, jeśli używasz dostawców checkoutu, hostingu lub newslettera.
- [ ] Nie zbieraj danych „na zapas”.
- [ ] Nie wysyłaj danych płatniczych e-mailem i nie zapisuj ich w repozytorium.
- [ ] Dodaj mechanizm zgód cookies tylko, jeśli wdrożysz technologie wymagające zgody.
- [ ] Sprawdź formularze, stopki, politykę prywatności i dostęp do skrzynek.
- [ ] Przetestuj procedurę obsługi żądania osoby, której dane dotyczą.
