# Legal checklist

- [ ] Ustal, kto jest sprzedawcą i uzupełnij komplet danych identyfikacyjnych.
- [ ] Zweryfikuj, czy sprzedaż będzie B2C, B2B czy mieszana.
- [ ] Oceń, czy forma działalności i sposób sprzedaży odpowiadają faktycznym czynnościom.
- [ ] Uzupełnij regulamin o proces zawarcia umowy, ceny, płatności, dostawę, reklamacje i kontakt.
- [ ] Zweryfikuj obowiązki informacyjne wobec konsumenta przed złożeniem zamówienia.
- [ ] Sprawdź zasady odstąpienia oraz wyjątki dotyczące treści cyfrowych.
- [ ] Zweryfikuj osobno wymogi dla zwierząt, dokumentacji pochodzenia i transportu.
- [ ] Zapisz datę oraz źródło każdej weryfikacji.
- [ ] Nie aktywuj checkoutu przed potwierdzeniem przez prawnika lub doradcę dopasowanego do realnego modelu.
