# Launch checklist

- [ ] Bramka legalna, podatkowa, CITES i prywatności ukończona.
- [ ] Dane sprzedawcy uzupełnione i sprawdzone.
- [ ] HTTPS działa na domenie głównej oraz www.
- [ ] Regulamin i polityka zawierają końcowe, zweryfikowane dane.
- [ ] Wybór checkoutu i dostawcy plików udokumentowany.
- [ ] Ewidencja sprzedaży istnieje poza GitHubem.
- [ ] Limity i alerty przychodu ustawione w niepublicznym arkuszu.
- [ ] Pierwszy produkt przeszedł test płatności i dostawy.
- [ ] Oświadczenia dla treści cyfrowej są wymagane wyłącznie, gdy faktycznie potrzebne, i nie są zaznaczone z góry.
- [ ] Ogłoszenia zwierząt mają kontakt, a nie koszyk; dokumentacja jest zweryfikowana dla każdego okazu.
- [ ] Zmieniono `salesEnabled` na `true` tylko po wszystkich powyższych punktach.
